this is the unofficial repo for an unofficial mod of super smash bros ultimate.
this repo is for development purposes only. this is separate from the final releases
and not intended to be used raw.

i do not own nor claim to own Bandai Namco or Nintendo's assets, including SSBU's original files. now with that all said...

![preview](https://github.com/user-attachments/assets/755d83ba-3822-4986-bf54-0bb030077444)
ui2k is a ui overhaul modpack for SSBU. The goal of this project is for players to travel from the title to the results screen with y2k-inspired graphics accompanying them. 
There are no balance changes, no costumes, and no custom stages. All changes are purely aesthetic; gameplay is 1 to 1 with vanilla for compatibility with online matches and
for people's existing costume, stage, music, etc mods.
